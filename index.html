Discord Message ID → 送信日時

DiscordのSnowflake形式のメッセージIDを入力すると、そのIDに埋め込まれた送信日時を復元します。DiscordのSnowflakeは、先頭42ビットがUTCミリ秒タイムスタンプです。

入力されたID
Discordエポック2015-01-01 00:00:00 UTC
生成されたUnixミリ秒
UTC日時
ローカル日時
Snowflakeパーツ

Discord Snowflake IDは64ビット整数です。上位42ビットがDiscordエポック(2015-01-01T00:00:00.000Z)からの経過ミリ秒になっています。残りはワーカーID、プロセスID、連番です。
